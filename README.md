# AWZ: Региональность

Модуль Bitrix CMS для региональной структуры сайта на доменах и поддоменах: для каждого региона — свои контакты, цены и тексты, а текущий регион определяется автоматически по адресу сайта.

<!-- desc-start -->

## Detailed Description

Модуль **AWZ: Региональность** (`awz.domains`) предназначен для ведения региональной структуры сайта на платформе 1C-Bitrix. Один сайт обслуживает все регионы: не нужно клонировать копии портала под каждый город или область — текущий регион определяется автоматически по адресу страницы (поддомен или отдельный домен).

### Основные возможности

#### Домены и поддомены

Регион привязывается к адресу сайта: поддомен или отдельный домен.

#### Региональные данные

Контакты, адреса и тексты подставляются по текущему региону посетителя.

#### SEO по регионам

Свои title и description у страниц каждого региона — без дублей между городами.

### Как работает

1. По адресу страницы (домен или поддомен) модуль определяет текущий регион посетителя
2. Список регионов ведётся в админке: домен, название, контакты и SEO-поля — всё в одном месте
3. Региональные данные выводятся в шаблонах через API модуля — править ядро и вёрстку не нужно

### Что это даёт

- **Меньше расходов на поддержку** — один портал вместо десятков копий под каждый регион
- **Выше позиции в регионах** — региональные страницы с уникальными тегами и текстами продвигаются в своём городе
- **Без программиста** — регионы, домены и данные настраиваются из админки
