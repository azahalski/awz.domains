# AWZ: Региональность (awz.domains)

SEO-региональность для 1С-Битрикс: город определяется по поддомену (`msk.site.ru`) или по сегменту URL (`site.ru/msk/link/`), данные города берутся из инфоблока и подставляются в контент макросами `#AWZ_S_*#`.

## Возможности

- Разные настройки для каждого сайта + общие настройки (наследование: пустое значение сайта = общее).
- Многодоменность: список основных доменов, поддомены городов ищутся относительно каждого.
- Код города: поддомен (`msk.site.ru` или полный домен как код), сегмент URL или оба варианта.
- Ранняя подмена URL города до загрузки ядра: `include/rewrite.php` подключается из `bitrix/php_interface/dbconn.php`, список городов — `dbcon_awz_d_cities_config.php` (обновляется автоматически при сохранении настроек и изменении элементов инфоблока; код города — константа `AWZ_D_CURRENT_CITY_CODE`).
- Ограничение подмены URL регулярками (`URL_REWRITE_REGEXPS`), подмена в title/H1.
- Событие `onCollectDefaultCode` — код города по умолчанию из обработчика разработчика.
- Маршрутизация URL-городов через `OnPageNotFound`: страницы `site.ru/msk/*` и главная города `site.ru/msk/` отдаются без 404 (сегмент вырезается, целевой файл инклюдится, город подставляется).
- Инфоблок городов создается по кнопке на странице настроек (тип инфоблока выбирается; инфоблок может быть свой для каждого сайта).
- Редирект на основной домен при неизвестном поддомене (301/302).
- Макросы `#AWZ_S_CODE#` с модификаторами через `~`: `#AWZ_S_PHONE~tel~default:Позвоните нам#`.
- Замена в title, meta-свойствах страницы и контенте (включаются настройками).
- Ролевая модель прав доступа (settview / settedit / rightview / rightedit).

## Макросы

- `#AWZ_S_NAME#` — название города, `#AWZ_S_CODE#` — код города.
- `#AWZ_S_<СВОЙСТВО>#` — значение свойства элемента инфоблока (список свойств в настройках).
- Дополнительные макросы из настроек: строки `CODE=VALUE`.
- Макросы разработчиков через событие `onCollectMacros` (приоритетнее системных).

## Модификаторы

`default:значение`, `upper`, `lower`, `ucfirst`, `lcfirst`, `trim`, `translit`, `phone`, `tel`, `plural:а|б|в`, `truncate:N`, `date:формат`, `number:N`, `replace:что|начто`, `wrap:до|после`, `part:N|разделитель`, `html`, `urlencode`, `sep:разделитель`.

Свои модификаторы — событие `onCollectModifiers`, своя замена контента — `onReplaceContent`.

## События для разработчиков

```php
$em = \Bitrix\Main\EventManager::getInstance();
$em->addEventHandler('awz.domains', 'onCollectMacros', function(\Bitrix\Main\Event $e){
    return new \Bitrix\Main\EventResult(
        \Bitrix\Main\EventResult::SUCCESS,
        ['MYMACROS' => 'значение'] // #AWZ_S_MYMACROS#
    );
});
```
