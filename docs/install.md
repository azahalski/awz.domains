# Установка модуля
<!-- install-start -->
## Технические требования
1) Модуль main выше 24.0.0
2) PHP 8.2+

\* *на более ранних версиях модуль и обновления к нему не тестируются*

## Установка

### Вариант 1 (Установка со страницы решения в Маркетплейс)

1) Перейдите на страницу решения в маркетплейс 1с-Битрикс [ссылка](https://marketplace.1c-bitrix.ru/solutions/awz.domains/)
2) Нажмите кнопку "**Установить**" и введите адрес вашего сайта
3) Отметьте необходимое решение для загрузки и нажмите кнопку "**Загрузить**"
4) Примите условия соглашения и нажмите кнопку применить, после этого решение будет загружено к вам на сайт
5) Нажмите кнопку "**Установить**"

### Вариант 2 (Установка с админ панели)

1) Перейдите в админ панели сайта на вкладку `Маркетплейс` - `Каталог решений`
2) Введите код модуля awz.domains
3) Нажмите кнопку "**Установить**"
4) Отметьте необходимое решение для загрузки и нажмите кнопку "**Загрузить**"
5) Примите условия соглашения и нажмите кнопку применить, после этого решение будет загружено к вам на сайт
6) Нажмите кнопку "**Установить**"

### Вариант 3 (Ручная установка)

1) Скачайте необходимую версию модуля со страницы [releases](https://github.com/azahalski/awz.domains/releases)
2) Распакуйте архив
3) **Если установка в Windows-1251** — перейдите в папку `/dist/`, распакуйте вложенный архив (результат — папка `.last_version`), переименуйте её в `awz.domains`
4) Скопируйте папку `awz.domains` в `\bitrix\modules\` вашего сайта
5) Установите модуль в админ панели: `Маркетплейс` -> `Установленные решения`, выберите модуль с кодом awz.domains и нажмите установить

## После установки

1) Откройте настройки модуля: `Настройки` - `Настройки модулей` - `AWZ: Региональность`
2) Добавьте регионы и привяжите их к доменам или поддоменам сайта
3) Заполните региональные данные: контакты, тексты и SEO-поля
